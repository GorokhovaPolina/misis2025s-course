### 1. ВВЕДЕНИЕ

Данный отчет описывает разработку программного обеспечения для обработки изображений, которое предназначено для разделения текста на две маски: исходный текст и зачеркнутый текст. Программа написана на языке C++ с использованием библиотеки OpenCV.

### 2. ОБЩЕЕ ОПИСАНИЕ СИСТЕМЫ

Система представляет собой консольное приложение, которое принимает на вход:
- Путь к исходному изображению
- Путь для сохранения маски зачеркивания
- Путь для сохранения маски записи

Основные компоненты системы:
- Класс `ImageProcessor` - основной класс для обработки изображений
- Модуль предварительной обработки изображений
- Модуль кластеризации цветов
- Модуль создания и расширения масок

### 3. ФУНКЦИОНАЛЬНОЕ НАЗНАЧЕНИЕ

Программа выполняет следующие функции:
1. Загрузка и предварительная обработка изображения
2. Удаление фона
3. Кластеризация цветов для разделения текста
4. Создание масок для исходного и зачеркнутого текста
5. Сохранение результатов обработки

### 4. ОПИСАНИЕ АЛГОРИТМОВ

#### 4.1 Предварительная обработка
1. Преобразование изображения в цветовое пространство HSV
2. Применение гауссовского размытия для уменьшения шума
3. Применение билатерального фильтра для сохранения границ

#### 4.2 Кластеризация цветов
1. Удаление фона с помощью пороговой обработки
2. Извлечение пикселей переднего плана
3. Кластеризация с использованием алгоритма k-means
4. Определение цветов исходного и зачеркнутого текста

#### 4.3 Создание масок
1. Создание начальных масок на основе кластеризации
2. Расширение масок с учетом цветовых характеристик
3. Уточнение границ масок

### 5. РЕЗУЛЬТАТЫ РАБОТЫ

Программа успешно выполняет следующие задачи:
- Корректно разделяет текст на две маски
- Сохраняет границы текста
- Обрабатывает различные типы зачеркиваний
- Устойчива к шумам и артефактам

### 6. ЗАКЛЮЧЕНИЕ

Разработанное программное обеспечение эффективно решает задачу разделения текста на исходный и зачеркнутый. Алгоритм показывает хорошие результаты на различных типах изображений и может быть использован в системах обработки документов.
