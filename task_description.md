# ОПИСАНИЕ ЗАДАЧИ КУРСОВОЙ РАБОТЫ

## Тема работы
Разработка алгоритма сегментации текстовых элементов с использованием методов кластерного анализа в пространстве HSV

## Постановка задачи

### Цель работы
Разработка программного обеспечения для автоматического разделения текста на две маски: исходный текст и зачеркнутый текст, с использованием методов компьютерного зрения и машинного обучения.

### Актуальность
В современном мире существует необходимость в автоматической обработке документов, содержащих зачеркнутый текст. Такая обработка требуется в различных областях:
- Архивное дело
- Юридическая документация
- Исторические исследования
- Системы электронного документооборота

### Задачи исследования
1. Разработка алгоритма предварительной обработки изображений:
   - Преобразование в цветовое пространство HSV
   - Удаление шума и артефактов
   - Сохранение границ текстовых элементов

2. Реализация алгоритма кластеризации цветов:
   - Удаление фона
   - Выделение текстовых элементов
   - Разделение текста на исходный и зачеркнутый

3. Создание системы создания и уточнения масок:
   - Генерация масок для разных типов текста
   - Расширение масок с учетом цветовых характеристик
   - Уточнение границ текстовых элементов

### Требования к программному обеспечению
1. Функциональные требования:
   - Загрузка изображения в форматах PNG, JPEG
   - Предварительная обработка изображения
   - Разделение текста на две маски

### Методы решения
1. Методы предварительной обработки:

### Подробное описание алгоритмов и функций

#### 1. Предварительная обработка изображения
Функция `preprocess()` класса `ImageProcessor`:
- Преобразует изображение в цветовое пространство HSV с помощью `cv::cvtColor()`
- Применяет гауссовское размытие с ядром 3x3 для уменьшения шума
- Использует билатеральную фильтрацию для сохранения границ при удалении шума
- Сохраняет промежуточный результат для отладки

#### 2. Кластеризация цветов
Функция `clusterColors(int k = 3)` класса `ImageProcessor`:
- Удаляет фон с помощью пороговой обработки в HSV пространстве
- Создает структуру `PixelData` для хранения HSV значений и позиций пикселей
- Выполняет k-means кластеризацию с учетом:
  - Цветовых характеристик (H, S, V)
  - Пространственного положения пикселей (x, y)
- Определяет цвета исходного и зачеркнутого текста на основе:
  - Размера кластеров
  - Средней насыщенности
  - Позиции в изображении

#### 3. Создание и расширение масок
Функция `expandMask()` класса `ImageProcessor`:
- Принимает параметры:
  - Исходная маска
  - HSV изображение
  - Референсный цвет
  - Максимальное расстояние
  - Количество итераций
- Расширяет маску с учетом:
  - Цветового расстояния в HSV пространстве
  - Морфологических операций
  - Пространственной близости

#### 4. Основной процесс обработки
Функция `process()` класса `ImageProcessor`:
1. Вызывает `preprocess()` для подготовки изображения
2. Выполняет `clusterColors()` для разделения цветов
3. Создает начальные маски на основе кластеризации
4. Расширяет маски с помощью `expandMask()`
5. Уточняет границы масок

#### 5. Сохранение результатов
Функция `saveMasks()` класса `ImageProcessor`:
- Сохраняет две маски:
  - Маска исходного текста
  - Маска зачеркнутого текста
- Использует формат PNG для сохранения бинарных масок

#### 6. Обработка ошибок
- Все функции обрабатывают исключения
- Проверяют корректность входных данных
- Выдают информативные сообщения об ошибках

#### 7. Оптимизация
- Использует эффективные структуры данных OpenCV
- Минимизирует копирование данных
- Применяет векторизованные операции где возможно
